# PRD (Product Requirements Document) - Controller Application

## 제품 개요

Cloud Event Ops Controller는 OpenSearch에 수집된 클라우드 이벤트를 실시간으로 감시하고,
운영자에게 반드시 전달해야 하는 이벤트를 식별하여 알림을 발송하는 핵심 애플리케이션입니다.

## 목표

1. 클라우드 이벤트 중 운영자 대응이 필요한 이벤트를 **자동으로 탐지**
2. 탐지된 이벤트를 **우선순위에 따라 분류**하고 적절한 채널로 **알림 발송**
3. RAG 기반 지식베이스를 활용하여 **판단 정확도 향상**

## 핵심 기능

### F1: 이벤트 감시 (Event Monitoring)
- OpenSearch에 인덱싱된 이벤트를 주기적으로 조회
- 마지막 처리 시점 이후의 새 이벤트 조회
- 조회 주기: 설정 가능 (기본 30초)

### F2: 이상징후 탐지 (Detection)
- 사전 정의된 탐지 룰(Detection Rules)과 이벤트 매칭
- 룰 기반 분류: P0 (긴급) / P1 (중요) / P2 (참고)
- RAG 기반 추가 판단 (선택적)

### F3: 알림 발송 (Alerting)
- 우선순위에 따른 알림 라우팅
- 중복 제거 및 쿨다운 적용
- Mattermost, Email, SMS 채널 지원

### F4: 에스컬레이션 (Escalation)
- P0 알림 미확인 시 상위 담당자에게 에스컬레이션
- 에스컬레이션 타임아웃 설정 가능

## 비기능 요구사항

- **지연**: 이벤트 인덱싱 후 알림까지 < 1분 (P0 기준)
- **가용성**: 99.9% (다중 인스턴스 배포)
- **확장성**: 이벤트 볼륨 증가에 따른 수평 확장
- **관측성**: 자체 메트릭 노출 (Prometheus)

## 사용자

- 클라우드 운영팀
- DevOps 엔지니어
- 보안 운영팀 (SecOps)
