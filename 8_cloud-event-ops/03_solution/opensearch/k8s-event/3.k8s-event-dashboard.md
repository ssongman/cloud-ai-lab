


# K8s Event 전용 Dashboard 구성 가이드



## 사전 조건

- Index Pattern `k8s-events-*` 생성 완료
- FluentBit → OpenSearch 이벤트 수집 정상 동작 확인



## 주요 필드 참조

FluentBit `kubernetes_events` input이 보내는 필드:

| 필드 | 설명 | 예시 |
|------|------|------|
| `@timestamp` | 이벤트 시간 | 2026-02-08T12:00:00Z |
| `type` | 이벤트 유형 | Normal, Warning |
| `reason` | 발생 사유 | FailedScheduling, ImagePullBackOff |
| `involvedObject.kind` | 대상 종류 | Pod, Node, PVC |
| `involvedObject.name` | 대상 이름 | my-pod-xxx |
| `involvedObject.namespace` | 네임스페이스 | default |
| `message` | 상세 메시지 | 0/3 nodes are available... |
| `count` | 반복 횟수 | 5 |
| `source.component` | 발생 소스 | kubelet, default-scheduler |

> 실제 필드명은 Discover에서 확인 후 맞춰야 함
> (예: `involvedObject.kind` 또는 `involvedObject.kind.keyword`)

## Panel ① : Event Type 비율 (Pie Chart)

> Normal vs Warning 비율을 한눈에 파악

### 설정

```
Visualization Type : Pie
Index Pattern      : k8s-events-*
```

### Metrics

```
Slice size : Count
```

### Buckets

```
Split slices:
  Aggregation : Terms
  Field       : type.keyword
  Size        : 5
  Order by    : Count (Descending)
```

### 저장

```
Title: [K8s] Event Type 비율 (Normal vs Warning)
```

> Apply changes 클릭 → Save 후 대시보드에 추가

## Panel ⑦ : 최근 Warning 메시지 (Saved Search)

> 원문 메시지를 시간순으로 확인

### 방법 (Discover 활용)

```
1. Discover 이동
2. Index Pattern : k8s-events-*
3. 필터 추가 : type.keyword is Warning
4. 표시 컬럼 선택 (좌측 필드 목록에서 + 클릭):
   - @timestamp
   - involvedObject.namespace
   - involvedObject.kind
   - involvedObject.name
   - reason
   - message
5. 시간순 정렬 (최신순)
6. Save → "K8s Warning Events - Latest"
```

### 대시보드에 추가

```
대시보드 → Add → Add existing → "K8s Warning Events - Latest" 선택
```

# 5. 유용한 필터 조합



## 빠른 장애 확인용

```
type.keyword           : Warning
reason.keyword         : CrashLoopBackOff OR FailedScheduling OR ImagePullBackOff
```



## 특정 Namespace 조사

```
involvedObject.namespace.keyword : production
type.keyword                     : Warning
```



## Node 문제 확인

```
involvedObject.kind.keyword : Node
reason.keyword              : NodeNotReady OR NodeHasDiskPressure OR NodeHasMemoryPressure
```



## Storage 문제 확인

```
reason.keyword : FailedMount OR FailedBinding
```

# 6. 필드명 트러블슈팅

Panel 생성 시 필드가 안 보이는 경우:

### (1) Index Pattern 필드 갱신

```
Management → Index Patterns → k8s-events-* → Refresh field list (우측 상단)
```

### (2) .keyword 접미사

- 문자열 필드를 Terms Aggregation에 쓸 때는 `.keyword` 붙여야 함
- 예: `reason` (X) → `reason.keyword` (O)

### (3) 실제 필드명 확인

```
Discover → k8s-events-* → 좌측 필드 목록에서 확인
```

또는 OpenSearch Dev Tools에서:

```json
GET k8s-events-*/_mapping
```
