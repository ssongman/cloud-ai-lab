* 02_architecture/overview.md

  * 목적 1~2문장 + 범위만 넣으면 전체가 정리됩니다.

* 03_solution/

  * “설치 스크립트 + 최소 설치 문서”**만 담도록 분리

* 04_controller/detection-and-alerting/

  * **운영자에게 전달해야 할 이벤트 탐지 로직(룰/정책)**

  * 룰을 P0/P1/P2로 나누면 나중에 커져도 관리가 쉽습니다.

  * Policies

    * “운영자에게 전달할지”는 **정책(Policy)** 입니다.
    * 코드가 아니라도 **Controller의 결정 로직**이므로 04에 두되,
    * “AP 개발 문서”와 섞이지 않게 **policies로 분리**합니다.

  * RAG-Knowledge

    * “전달 여부 판단”을 LLM/RAG로 보강하려면 아래와 같은 근거 데이터 필요

      * 기준(criteria)
      * 대응 플레이북(playbooks)
      * 라벨링 예시(examples)
